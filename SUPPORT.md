# Getting Help

- **Stuck on a quest?** Ask in [Discussions Q&A](../../discussions/categories/community-help)
  (paste your command + full output — "it doesn't work" gets no answer).
- **Found a mistake?** Open a [bug report](../../issues/new/choose) with the quest ID.
- **Have an idea?** Open a [quest idea](../../issues/new/choose) or start an
  [Ideas discussion](../../discussions/categories/ideas).
- **Show off:** finished the capstone? Post it in
  [Show and tell](../../discussions/categories/show-and-tell) and add it to `SHOWCASE.md`.

Maintainer response target: 48 hours. Peer answers welcome anytime.
