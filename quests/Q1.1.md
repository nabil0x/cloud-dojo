# Q1.1 — S3 buckets and objects (30 XP)

**Phase:** Phase 1 — First AWS Services

## Concept
S3 is object storage: buckets hold objects, and each object is a key plus bytes plus metadata. There are no real folders; keys that contain `/` only look hierarchical to your eyes.

You talk to S3 with the AWS CLI pointed at the emulator's endpoint. The full lifecycle, create a bucket, upload, list, download, and delete, uses the exact same operations whether the backend is the emulator or real AWS. Learning keys and buckets now makes every later service easier, because most of them store their data the same way.

## Uses
- Store files, images, logs, and backups durably and cheaply.
- Host static websites straight from a bucket.
- Stage data between services in a pipeline.
- Hold large datasets for analytics and ML training.
- Act as the source and destination for Lambda and ETL jobs.

## Key info
- Every command needs the endpoint: `--endpoint-url=http://localhost:4566`.
- Make a bucket: `aws --endpoint-url=http://localhost:4566 s3 mb s3://dojo-bucket`.
- Upload: `aws --endpoint-url=http://localhost:4566 s3 cp file.txt s3://dojo-bucket/`.
- List: `aws --endpoint-url=http://localhost:4566 s3 ls s3://dojo-bucket`.
- Download: `aws --endpoint-url=http://localhost:4566 s3 cp s3://dojo-bucket/file.txt .`.
- Delete one object: `aws --endpoint-url=http://localhost:4566 s3 rm s3://dojo-bucket/file.txt`.
- Remove the bucket itself: `aws --endpoint-url=http://localhost:4566 s3 rb s3://dojo-bucket`.
- Bucket names must be lowercase, globally unique, and DNS-safe.
- `s3 ls` with no bucket lists every bucket; useful to confirm creation.
- S3 keys can be any UTF-8 string; `/` is just a character, not a folder.
- `s3 sync` copies a whole directory tree, handy when you have many files.

## Pitfalls
- Forgetting `--endpoint-url` sends commands to real AWS, where they fail without real credentials.
- Uppercase letters or underscores in a bucket name are rejected; keep names lowercase and hyphenated.
- Listing a prefix needs the trailing slash, for example `s3://dojo-bucket/`, or the output looks wrong.
