# Q2.2 — Add the app service (40 XP)

**Phase:** Phase 2 — Compose Capstone

## Concept
Now the stack stops being just an emulator and becomes an application.
The `app/` folder holds a small Python service (`app.py`) and its `Dockerfile`, already scaffolded for you.
Compose builds that image locally through `build: ./app` instead of pulling it, then runs it as a second service next to the emulator.
Two services on one Compose network talk to each other by name, and the app is configured with `AWS_ENDPOINT_URL=http://emulator:4566` so its AWS calls land on the emulator container, not the public internet.
The `/health` endpoint proves the web server is up; `/s3` proves the app can reach AWS APIs through the emulator.
This is where both halves of the mental model finally meet: a real HTTP app talking to a real, emulated cloud.

## Uses
- Local end-to-end testing where a web service talks to cloud APIs without leaving your laptop.
- Reproducing a bug that only appears when the app and the cloud service run together.
- Demoing a backend to a teammate with one command and zero cloud spend.
- Practicing container networking and environment-variable configuration.
- Building the multi-service habit that later becomes ECS or Kubernetes.

## Key info
- Read the scaffold first: `app/app.py` and `app/Dockerfile`.
- Build and start everything: `docker compose up -d --build`
- Check the web server: `curl localhost:8080/health`
- Check the AWS path: `curl localhost:8080/s3`
- The app reads its endpoint from `AWS_ENDPOINT_URL`, set in `compose.yaml` under the app service's `environment:`.
- `--build` forces a fresh image build. Without it, Compose may reuse an old image and silently ignore your edits.
- Rebuild one service only: `docker compose up -d --build app`

## Pitfalls
- Editing `app.py` and forgetting `--build`, then wondering why nothing changed.
- Expecting `/s3` to list buckets before the seed script has run. An empty list is the emulator working correctly, not a failure.
- Mixing up the two ports: 8080 is your app, 4566 is the emulator.
