Q7.3 — Pipeline pushes to ECR by SHA (30 XP)

Phase: Phase 7 — CI/CD + ECS

Concept

Continuous delivery picks up where CI ends: a green build becomes a shippable artifact. Here the artifact is a container image in ECR, and the key idea is immutability. Tag every build with the git commit SHA, like dojo-app:abc1234, instead of a moving latest. A SHA tag points at exactly one commit forever, so a deploy is traceable and a rollback is just redeploying the previous SHA.

To push, the pipeline must authenticate to AWS. The safe modern way is OIDC: GitHub assumes a short-lived IAM role with no long-lived keys stored as secrets. This quest extends the workflow to log in, build, tag with the SHA, and push.

Then you change one string in the app, push, and confirm a brand-new SHA tag appears.

Uses

  • Traceable releases: every running image maps back to a commit.
  • One-command rollback: redeploy the previous SHA, no rebuild needed.
  • Keyless auth: OIDC removes long-lived AWS keys from CI secrets.
  • Artifact promotion: the same built image moves between environments.
  • Audit: ECR image history shows who shipped what and when.

Key info

  • Authenticate and push by SHA:

      - uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: arn:aws:iam::<acct>:role/gh-actions
          aws-region: us-east-1
      - uses: aws-actions/amazon-ecr-login@v2
      - run: |
          IMG=<acct>.dkr.ecr.us-east-1.amazonaws.com/dojo-app
          docker build -t $IMG:${{ github.sha }} .
          docker push $IMG:${{ github.sha }}
  • ${{ github.sha }} is the full commit hash, so each push produces a unique tag.
  • The OIDC role trusts GitHub's token; no AWS_SECRET_ACCESS_KEY needed.
  • Verify with aws ecr describe-images --repository-name dojo-app.

Pitfalls

  • Storing long-lived AWS keys as repo secrets when OIDC is available.
  • Deploying latest instead of the SHA, which loses the commit-to-image link.
  • Region mismatch between the login command, the repo, and the deploy, so the push lands nowhere or fails.
