Q6.2 — Variables + outputs (25 XP)

Phase: Phase 6 — Terraform IaC

Concept

Hardcoding values makes config brittle: every environment needs an edit, and edits drift. Variables let you parameterize a config once and feed it different values per environment. A variable block declares an input with an optional default, and a terraform.tfvars file supplies the actual values.

Outputs are the other half: they expose useful values (an ARN, an endpoint) after apply, for humans reading the terminal and for other config to consume. This quest parameterizes the bucket name and outputs its ARN.

Then you change the variable and re-plan to see a critical Terraform behavior: a bucket name is a force-new attribute, so changing it proposes destroying the old bucket and creating a new one.

Uses

  • One config, many environments: same HCL, different .tfvars for dev and prod.
  • Secrets and sizes stay out of code: pass region, instance size, or tags at apply time.
  • Module interfaces: variables in, outputs out is exactly how reusable modules compose.
  • Chaining resources: one config consumes another's output as an input.
  • Automation: CI sets variable values without editing tracked files.

Key info

  • Declare an input and give the bucket a variable name:

variable "bucket_name" {
  type    = string
  default = "dojo-first-bucket"
}

resource "aws_s3_bucket" "dojo" {
  bucket = var.bucket_name
}

output "bucket_arn" {
  value = aws_s3_bucket.dojo.arn
}
  • terraform.tfvars supplies values: bucket_name = "dojo-renamed-bucket".
  • terraform output prints outputs; terraform output -json is machine-readable.
  • Watch the plan for # forces replacement next to the bucket name.

Pitfalls

  • Changing a force-new attribute without realizing it deletes and recreates the resource. For a bucket, that means data loss.
  • Committing a .tfvars file that holds secrets. Use separate secret-free files plus environment variables or a secrets backend.
  • Referencing var.x with no default and no value supplied, which fails with an unclear "variable not set" error.
