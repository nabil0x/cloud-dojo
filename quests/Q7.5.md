# Q7.5 👹 Boss: push-to-deploy + teardown (25 XP)

**Phase:** Phase 7 — CI/CD + ECS

## Concept
This boss quest closes the loop from commit to live and then closes the wallet. First you change the app, push, and watch the pipeline rebuild the image and ECS roll out a new task revision that serves traffic. That end-to-end flow, sometimes called push-to-deploy, is the real deliverable of Phase 7: no laptop builds, no console clicks, just a commit.

Then you tear it all down. Scaling the service to zero stops the task billing while keeping the config; deleting the service, cluster, and task definition removes the rest. You finish by proving the cluster has no services and noting the billing state.

A forgotten Fargate service is a subscription you did not sign up for, so teardown is a skill, not an afterthought.

## Uses
- Push-to-deploy: a merged commit reaches production with no manual step.
- Fast iteration: ship a small change and see it live in minutes.
- Safe rollback: redeploy the previous SHA-tagged image.
- Cost control: scale to zero between work sessions, delete when finished.
- Clean handover: an empty cluster means no surprise charges later.

## Key info
- Trigger a new rollout and then confirm it serves:

```bash
aws ecs update-service --cluster dojo --service dojo-svc --force-new-deployment
aws ecs describe-services --cluster dojo --services dojo-svc \
  --query 'services[0].{running:runningCount,taskDef:taskDefinition}'
```

- Teardown in order:

```bash
aws ecs update-service --cluster dojo --service dojo-svc --desired-count 0
aws ecs delete-service --cluster dojo --service dojo-svc --force
aws ecs delete-cluster --cluster dojo
aws ecs list-services --cluster dojo
```

- `list-services` returning an empty list is the clean proof.
- Note any leftover cost: log groups, ECR storage, or a stray load balancer.

## Pitfalls
- Leaving the service running after the demo, so Fargate bills every hour.
- Deploying from your laptop with `docker push` or a console click. Every deploy must go through the pipeline.
- Deleting the cluster while tasks are still running, or forgetting the log group and ECR images that also cost.

## Done check
paste the deploy log tail + the post-teardown `list-services` (empty) + billing note. Par: commit-to-live under 10 minutes, $0 left behind.
