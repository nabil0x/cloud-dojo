# Q5.5 👹 Boss: $0 audit (25 XP)

**Phase:** Phase 5 — Bedrock + SageMaker

## Concept
This boss turns cost discipline into reflex. Bedrock and SageMaker run three meters at once: tokens (every API call), instance-hours (endpoints, notebook instances, training jobs), and storage (artifacts, snapshots, vector stores). Any of them left running bills quietly.

The audit is a checklist you walk end to end: no endpoints, no notebook instances running, no training jobs stuck `InProgress`, and Knowledge Base data sources you actually understand. Then you open billing and confirm $0 or sandbox-clean.

Write down the real per-unit costs you observed, such as per-1k-tokens and endpoint dollars per hour. That last step is what makes the number concrete and the habit durable.

The point isn't just a clean account; it's the confidence that lets you experiment fearlessly because you know you can always clean up and verify. That muscle is the real prize of Phase 5.

## Uses
- End every AI experiment cleanly instead of discovering the bill next month.
- Build the reflex to note a rate before creating anything billable and verify after deleting.
- Understand which SageMaker and Bedrock resources are the usual orphaned-cost suspects.
- Keep shared sandbox accounts at $0 so teammates aren't surprised by your leftovers.
- Turn cost review into a routine you carry to any cloud account, work or personal.

## Key info
- Verify no endpoints: `aws sagemaker list-endpoints`.
- Verify no notebook instances: `aws sagemaker list-notebook-instances` (check for `InService`).
- Verify no stuck jobs: `aws sagemaker list-training-jobs --status-equals InProgress`.
- Confirm Knowledge Base data sources and delete the ones you no longer need.
- Open Billing → Cost Explorer for the current period and confirm $0 / sandbox-clean.
- Write the observed costs: Bedrock per-1k input and output tokens, SageMaker endpoint $/hr, notebook instance $/hr, artifact storage rate.
- Real AWS only; this phase has no meaningful emulator, so cleanup is the whole game.

## Pitfalls
- Checking the console but missing a notebook instance or endpoint that the console hides under a filter.
- Leaving a training job in `InProgress` because it "looks finished"; confirm the actual status.
- Skipping the cost notes, so the per-unit rates never stick and the next lab overshoots budget.

## Done check
Paste the resource-cleanup checklist + the cost notes. This is the muscle that lets you experiment fearlessly forever.
