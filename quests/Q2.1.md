# Q2.1 — Stack up the emulator (30 XP)

**Phase:** Phase 2 — Compose Capstone

## Concept
Docker Compose describes a whole multi-container environment in one YAML file.
Each entry under `services:` is a single container role, and Compose wires up a private network where every service reaches the others by name.
The emulator (MiniStack by default, LocalStack as a swap) is the first service in your stack, and bringing it up alone proves your `compose.yaml` is valid before anything else joins.
Running `docker compose up -d emulator` starts just that one service in the background so your terminal stays free.
The emulator listens on port 4566 inside the Compose network, and the port mapping exposes that same port on your laptop.
From here on, every `aws` command or `curl` you point at `http://localhost:4566` reaches the emulator, and that endpoint is the foundation later quests build on.

## Uses
- Spin up a full local AWS-like environment for development without an AWS account.
- Give every teammate the same services with one `docker compose up`, no manual setup.
- Run integration tests against real APIs (S3, SQS, DynamoDB) without paying or touching the cloud.
- Prototype an app locally before committing to production infrastructure.
- Learn Compose the same way you will later describe ECS tasks and services.

## Key info
- Start just the emulator: `cd phase-02-compose && docker compose up -d emulator`
- Confirm it is alive: `curl -s http://localhost:4566/_ministack/health`
- Inspect running containers: `docker compose ps`
- Follow one service's logs: `docker compose logs -f emulator`
- Default image is MiniStack (no signup). To swap to LocalStack, change `image:` and add `LOCALSTACK_AUTH_TOKEN`; the port stays 4566.
- Fake credentials are fine locally. Region plus placeholder `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` come from the stack's `environment:`.
- Stop without deleting data: `docker compose stop emulator`

## Pitfalls
- Forgetting `-d` leaves the stack in the foreground and blocks your terminal.
- Assuming `up` waits for readiness. It starts containers; it does not guarantee the emulator finished booting, so give it a second before hitting health.
- Running `docker compose up` from the wrong folder. Compose reads `compose.yaml` from the current directory, so `cd phase-02-compose` first.
