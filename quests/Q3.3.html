Q3.3 — Create + invoke (40 XP)

Phase: Phase 3 — Lambda Container Images

Concept

Now the image becomes a function.

create-function with --package-type Image and a --code ImageUri=<uri> registers the pushed image as a Lambda function.

You do not pass --handler or --runtime for image functions, because the image already declares both through its CMD and base image.

Once created, invoke calls it synchronously with a test payload and writes the response to a file, so you can read exactly what the code returned.

This is the full loop made real: build, push, register, invoke.

The same commands work against real AWS, where the execution role you attach decides which APIs the function may call.

Uses

  • Testing a function with a controlled payload before wiring any trigger.
  • Verifying that an image-based function starts and runs correctly.
  • Running one-off serverless jobs on demand.
  • Debugging handler logic in isolation from its event source.
  • Re-invoking with different payloads to check edge cases quickly.

Key info

  • Create: aws --endpoint-url http://localhost:4566 lambda create-function --function-name dojo-lambda --package-type Image --code ImageUri=<your pushed URI> --role <role-arn>
  • Invoke: aws --endpoint-url http://localhost:4566 lambda invoke --function-name dojo-lambda --payload '{"key":"value"}' out.json
  • Read the result: cat out.json
  • Image functions need no --handler or --runtime; the image supplies them.
  • The --role is the execution role. On the emulator it is decorative; on real AWS it gates every API call.
  • Check status while debugging: aws --endpoint-url http://localhost:4566 lambda get-function --function-name dojo-lambda
  • Logs from an invoke land in the function's CloudWatch log group, which is how you see print output.
  • For larger events, pass a file instead of inline JSON: --payload file://event.json.

Pitfalls

  • Passing --handler or --runtime for an image function, which the API rejects.
  • Pointing --code ImageUri at an untagged or wrong-architecture image, so the function fails to start.
  • Ignoring out.json and assuming success, since invoke returns status separately from the function's payload.
