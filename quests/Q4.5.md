# Q4.5 👹 Boss: nuke it + $0 proof (25 XP)

**Phase:** Phase 4 — EC2 + VPC + RDS

## Concept
This is the cleanup boss, and it's the most important quest in the phase. Every resource you launched has a meter: EC2 bills per second, RDS per hour, EBS volumes and snapshots per GB-month, Elastic IPs per hour while unattached, NAT gateways per hour plus per GB.

Deleting the obvious instance isn't enough, because orphaned disks, snapshots, and IPs keep billing silently. The skill is a full teardown followed by proof: verify in Billing or Cost Explorer that the account is at $0 or sandbox-clean.

Then name what would have billed had you walked away. Being able to list the meters is what makes the cleanup real instead of a checkbox.

Do this every session until it's reflex. Par for this quest is nothing left running and no stray billable resource hiding in the background.

## Uses
- Prevent the classic "forgot it was running" bill on personal and work accounts alike.
- Build a repeatable teardown checklist you can apply after every lab or experiment.
- Learn to read Cost Explorer, the single best habit for experimenting without fear.
- Understand which resource types are the usual suspects for orphaned charges: EBS, snapshots, EIPs, NAT.
- Practice the same discipline you'll need with SageMaker endpoints and Bedrock jobs in Phase 5.

## Key info
- Terminate instances: `aws ec2 terminate-instances --instance-ids <id>` (confirm state `terminated`).
- Delete RDS: `aws rds delete-db-instance --db-instance-identifier <id> --skip-final-snapshot`.
- Release Elastic IPs: `aws ec2 release-address --allocation-id <id>`.
- Delete unattached volumes: `aws ec2 describe-volumes --filters Name=status,Values=available`, then `aws ec2 delete-volume --volume-id <id>`.
- Delete leftover snapshots: `aws ec2 describe-snapshots --owner-ids self`, then `aws ec2 delete-snapshot`.
- Verify: open Billing → Cost Explorer, set the range to this month, confirm $0 / sandbox-clean.
- Name what would have billed: EC2 instance-hours, RDS instance-hours, EBS GB-month, snapshot GB-month, unattached EIP hours, NAT gateway hours + data.

## Pitfalls
- Terminating the instance but forgetting its unattached EBS volume or its AMI snapshots.
- Leaving an Elastic IP allocated after releasing the instance; an unattached EIP still bills.
- Trusting the console's default view instead of explicitly checking Cost Explorer for the current period.

## Done check
Paste the resource-terminated confirmations + the billing screenshot description. Par: nothing left running.
