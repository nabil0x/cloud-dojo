# Q0.2 — Run the emulator (15 XP)

**Phase:** Phase 0 — Docker Foundations

## Concept
An emulator is a local service that speaks the same HTTP APIs as a cloud provider. MiniStack emulates many AWS services on a single port (`4566`), so you can create buckets and queues with no AWS account and no bill.

Running it in a container keeps your machine clean and makes the whole thing disposable. This quest proves you can start a long-running service in the background and reach it from your host. Detached mode plus a stable name plus a port mapping is the shape of every service container you'll run for the rest of the course.

## Uses
- Learn AWS APIs offline with zero cost and zero account setup.
- Run integration tests in CI without touching a real cloud.
- Prototype a data pipeline before committing to real infrastructure.
- Share a repro environment that behaves the same on every laptop.
- Tear down and recreate the whole stack in seconds.

## Key info
- Start it: `docker run -d --name dojo-emu -p 4566:4566 ministackorg/ministack`.
- `-d` runs detached in the background; `-p host:container` publishes the port.
- `--name dojo-emu` gives the container a stable handle you'll reuse everywhere.
- Check it's up: `docker ps`.
- Health check: `curl -s http://localhost:4566/_ministack/health`.
- `curl` returns JSON; a connection error means the container isn't running or the port isn't mapped.
- Data lives in the container's writable layer by default and dies with it; a volume fixes that in Q1.4.
- The emulator ignores credentials, but the CLI still wants them set; use fake `test`/`test`.
- `docker logs dojo-emu` shows the startup output if something looks wrong.
- `docker stop dojo-emu` and `docker start dojo-emu` cycle it without losing the name.
- `http://localhost:4566` is the endpoint every Phase 1 command builds on.

## Pitfalls
- Forgetting `-d` makes the terminal block on the container's foreground output; use `Ctrl+C` and re-run with `-d`.
- Port `4566` already in use means another process owns it; find it with `docker ps` or map a different host port like `-p 4570:4566`.
- A name collision on `dojo-emu` means a container already exists; remove it with `docker rm -f dojo-emu` or pick a new name.
