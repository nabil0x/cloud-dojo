# Q0.4 — Your first Dockerfile (20 XP)

**Phase:** Phase 0 — Docker Foundations

## Concept
A Dockerfile is a text recipe that tells Docker how to build an image, one instruction at a time. Each instruction (`FROM`, `COPY`, and so on) becomes a cached layer, and the finished stack of layers is your image.

Here you start from an existing base (`nginx:alpine`) and drop in your own `index.html`, turning a generic web server into your site. Building tags the result so you can run it like any other image. `EXPOSE` only documents the port; the actual publishing happens at run time with `-p`.

## Uses
- Ship a static site in an image that runs identically anywhere.
- Bake configuration and assets into a repeatable, versioned artifact.
- Replace hand-configured servers with a build anyone can reproduce.
- Create a foundation image your team extends for real services.
- Learn the exact syntax every later Dockerfile in this course reuses.

## Key info
- A 3-line Dockerfile: `FROM nginx:alpine`, then `COPY index.html /usr/share/nginx/html/index.html`, then `EXPOSE 80`.
- Build it: `docker build -t dojo-site .` (the trailing `.` is the build context).
- Run it: `docker run -d -p 8081:80 dojo-site`.
- List images: `docker images`; filter with `docker images | grep dojo-site`.
- Verify the page: `curl -s localhost:8081`.
- `-t dojo-site` tags the image with a readable name and default `latest`.
- The build context is the folder you pass; files outside it can't be `COPY`'d.
- `nginx:alpine` is a small base, which keeps the image and pulls fast.
- `docker run --rm` auto-removes the container when it exits, good for one-off tests.
- Layer order in the Dockerfile drives both build speed and final image size.
- `docker build` prints each step number as the layers form.

## Pitfalls
- The file must exist in the build context; `COPY` fails if it's outside the folder.
- `EXPOSE` doesn't open anything by itself; without `-p` the host can't reach the container.
- Using `nginx` instead of `nginx:alpine` pulls a much larger base; tags and variants matter.
