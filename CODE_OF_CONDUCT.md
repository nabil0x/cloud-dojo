# Code of Conduct (Cloud Dojo)

## Pledge
A harassment-free learning space for everyone, regardless of experience level,
background, or identity. Beginners asking "obvious" questions are the point of this repo.

## Standards
- Be kind, specific, and patient in issues, PRs, and reviews.
- Critique the quest, never the learner. No gatekeeping, no dunking.
- Paste errors and Done checks; help others reproduce before theorizing.

## Unacceptable
Harassment, insults, spam, credential-sharing, or instructions that leave
billable cloud resources running on someone else's account.

## Enforcement
Violations → warning → temporary ban → permanent ban, at maintainer discretion.
Report via a private issue or DM to the maintainer. All reports stay confidential.
