# Curated Resources — beyond the dojo

Hand-picked, free-first. Official docs before blogs, practice before theory.

## Free sandboxes (no card, real AWS)
- [AWS Builder Center Sandbox](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-builder-center-sandbox) — real resources, 8 hrs/week, auto-cleaned. Use for Track T.
- [AWS Educate](https://aws.amazon.com/education/awseducate/) — free labs + credits path for students.
- [AWS Skill Builder free tier](https://skillbuilder.aws/) — 600+ free courses, free Builder Labs.
