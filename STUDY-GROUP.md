# Study Group Runbook — learn the dojo with people

Solo works. Cohorts finish. Pick one.

## Format (8 weeks, 1 hr/week call + async quests)
| Week | Phase | Call agenda (30 min) |
|---|---|---|
| 1 | 0 Docker | hello-world live, fix everyone's install together |
| 2 | 1 AWS services | compare `s3 ls` outputs, argue about SNS vs SQS |
| 3 | 2 Compose | screen-share the DNS lesson (Q2.3) breaking live |
| 4 | 3 Lambda | invoke party: everyone triggers everyone else's function |
| 5 | 4 EC2/VPC | whiteboard SGs vs NACLs from memory |
| 6 | 5 Bedrock | prompt battle: same question, best grounded answer wins |
| 7 | 6–7 IaC/CI | destroy + rebuild race ( fastest clean `plan` wins) |
| 8 | 8 Capstone | demos + retros, vote Grandmaster |

## Roles (rotate weekly)
- **Host** — runs the call, keeps time, merges the week's notes.
- **Debugger** — owns unblocking stuck members async (Discussions Q&A).
- **Demo** — screenshares one quest Done check, narrates the thinking.

## Rules
1. Quests async, bosses together (boss fights are call events).
2. Done checks pasted in the group chat, not "it works".
3. Stuck > 20 min → ask. Answering earns nothing; asking costs nothing.
4. Teardown rule is collective: nobody sleeps while shared sandbox resources run.

## Threads (GitHub Discussions)
One `show-and-tell` thread per cohort (`cohort-YYYY-MM`), weekly check-in comments,
capstone demo links. Future cohorts read old threads — write like it.
